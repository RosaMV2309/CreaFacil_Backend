# CreaFacil_Backend

Servidor y API REST de **CreaFácil**: aplicación multiplataforma para la gestión de pedidos, cotizaciones y planificación de trabajos personalizados (manualidades, decoraciones y murales).

- Tecnología: Node.js + Express + TypeScript + Prisma + PostgreSQL
- Especificación: DERCAS v1.0 (Rosa Virginia Moreira Vidal, Sexto B)

## Ramas

- `main`: versiones estables.
- `develop`: integración. Todo cambio entra por Pull Request desde `feature/*`, `fix/*` o `refactor/*`.
